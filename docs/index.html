SIMPLE_CONSOLE

Console manipulation with colors and cursor control

Overview Quick Start API Reference Colors GitHub

Overview

SIMPLE_CONSOLE provides console manipulation for Eiffel applications on Windows with colored text, cursor control, and screen operations.

Key Features

  • 16 foreground/background colors
  • Cursor positioning
  • Screen/line clearing
  • Console title setting
  • Hidden (no-echo) line input for password prompts
  • Thread-safe (SCOOP-compatible)

Quick Start

<library name="simple_console" location="$SIMPLE_CONSOLE/simple_console.ecf"/>

Basic Usage

local
    con: SIMPLE_CONSOLE
do
    create con

    -- Print colored text
    con.print_colored ("Success!", con.Green)
    con.print_colored ("Error!", con.Red)

    -- Position and print
    con.set_cursor (10, 5)
    print ("Hello")

    -- Clear screen
    con.clear
end

Screen

FeatureDescription
clearClear screen

width, heightConsole dimensions
set_title (text)Set window title

Input

FeatureDescription
is_stdin_consoleIs standard input a console, rather than a file or a pipe?
read_hidden_lineRead one line of standard input without echoing it; Void on end of input, never a partial line

When standard input is a console, read_hidden_line clears ENABLE_ECHO_INPUT for the read (keeping line editing and Ctrl+C), reads through ReadConsoleW in UTF-16 so a Hebrew or Greek password survives, and restores the previous console mode on every exit path. When standard input is redirected from a file or a pipe - as an installer's verification script feeds it - the line is read the ordinary way, decoded as UTF-8, and no console mode is touched. Both paths strip the trailing CR/LF.

if attached con.read_hidden_line as l_password then
    create_admin (l_password)
end
